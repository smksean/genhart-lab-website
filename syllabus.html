How the 3-month roadmap works

Understand the path from foundations to project build, portfolio polish, and interview readiness.
Month 1

Foundations for Applied AI Work

Goal: Build a repeatable project workflow.

  • Applied ML project workflows
  • Real-world problem framing
  • Dataset choice, cleaning, exploration, and feature engineering
  • Baseline models and project mistakes to avoid
  • Professional GitHub repository structure

Outcome: You should understand how to approach an applied ML project from problem to first model.

Month 2

Building Real-World ML Projects

Goal: Strengthen evaluation and production awareness.

  • Model selection and comparison
  • Evaluation metrics beyond accuracy
  • Validation strategy and error analysis
  • Explainability and model limitations
  • Dashboards, APIs, demos, and technical reports

Outcome: You should have at least one strong applied project that is technically explainable and portfolio-ready.

Month 3

Portfolio, Deployment Thinking, and Interview Confidence

Goal: Turn project work into interview-ready evidence.

  • Complete 2 to 3 portfolio projects
  • Improve GitHub presentation
  • Write LinkedIn-ready case studies
  • Prepare project walkthroughs and practise interview explanations
  • Communicate trade-offs, limitations, and domain value

Outcome: You should be able to present your work clearly and defend the decisions behind it.
